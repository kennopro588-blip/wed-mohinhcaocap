# LUXE MODELS - Mô Hình Cao Cấp

Website thương mại điện tử bán mô hình cao cấp (Gundam, Supercar, Figure...) được xây dựng bằng **Next.js** + **Spring Boot** + **MySQL**.

## Tính năng

- 🛒 Mua sắm trực tuyến với giỏ hàng & thanh toán VNPay
- 🎁 Hệ thống Voucher, Nhiệm vụ & Vòng quay may mắn
- 👑 Gói Hội Viên VIP 30 Ngày (freeship & giảm giá)
- 🤖 AI Chat hỗ trợ tư vấn sản phẩm
- 📊 Admin Dashboard: POS, Doanh thu, Nhân viên, Tồn kho
- 💳 Tích hợp thanh toán VNPay

## Công nghệ

| Phần | Công nghệ |
|---|---|
| Frontend | Next.js 15, TypeScript, CSS Modules |
| Backend | Spring Boot 3.4, Java 17, JPA |
| Database | MySQL (XAMPP) |
| Payment | VNPay |

## Cài đặt

1. Import `wed-mohinhcaocap.sql` vào MySQL
2. Chạy Backend: `cd Backend && mvnw spring-boot:run`
3. Chạy Frontend: `cd Frontend && npm install && npm run dev`
4. Truy cập: `http://localhost:3000`
